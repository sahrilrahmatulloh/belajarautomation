Selamat, kamu sudah menyelesaikan dasar-dasar QA. Lalu, langkah apa berikutnya?

## Jalur karier QA

| Jalur | Fokus |
|---|---|
| Manual QA Engineer | Analisis kebutuhan, test case, eksplorasi |
| QA Automation Engineer | Menulis script pengujian otomatis |
| SDET | Membangun framework dan tool pengujian |
| QA Lead | Mengatur strategi dan tim QA |

## Langkah berikutnya

1. **Latih dasar-dasarmu.** Kerjakan Kuis QA Fundamental dan latihan Test Case di Playground.
2. **Pelajari dasar web dan API.** Pahami client-server, HTTP, dan DevTools.
3. **Belajar satu bahasa pemrograman.** JavaScript, TypeScript, atau Java adalah pilihan populer.
4. **Masuk ke automation.** Mulai dari Playwright untuk web automation.
5. **Bangun portofolio.** Simpan test case, bug report, dan project automation di GitHub.

<Tips>Konsisten lebih penting daripada cepat. Belajar 30 menit setiap hari lebih efektif daripada belajar lama sesekali.</Tips>

## Ringkasan

Fondasi QA sudah kamu kuasai. Lanjutkan ke Kuis QA Fundamental untuk menguji pemahamanmu, lalu ikuti roadmap sesuai jalur karier yang kamu pilih.
