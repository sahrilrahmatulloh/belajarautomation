Jika SDLC adalah alur membuat software, **Software Testing Life Cycle (STLC)** adalah alur kerja pengujiannya.

## Tahapan STLC

1. **Analisis kebutuhan.** Memahami apa yang harus diuji dari dokumen kebutuhan.
2. **Perencanaan test.** Menentukan ruang lingkup, strategi, jadwal, dan sumber daya.
3. **Desain test case.** Menulis test scenario, test case, dan menyiapkan data uji.
4. **Persiapan lingkungan.** Menyiapkan server, akun uji, dan perangkat.
5. **Eksekusi test.** Menjalankan test case dan mencatat hasilnya.
6. **Penutupan test.** Membuat laporan hasil pengujian dan evaluasi.

## Entry dan exit criteria

Setiap tahap punya syarat masuk (**entry criteria**) dan syarat selesai (**exit criteria**).

| Tahap | Contoh entry criteria | Contoh exit criteria |
|---|---|---|
| Desain test case | Kebutuhan sudah disetujui | Test case sudah ditinjau |
| Eksekusi test | Build siap diuji | Semua test dijalankan, bug kritis tertutup |

<Peringatan>Urutan tahap penting. Menjalankan test sebelum memahami kebutuhan membuat pengujian tidak terarah.</Peringatan>

## Ringkasan

Urutan STLC: analisis kebutuhan, perencanaan test, desain test case, persiapan lingkungan, eksekusi test, lalu penutupan test.
