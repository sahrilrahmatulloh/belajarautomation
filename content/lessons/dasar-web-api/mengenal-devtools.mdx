Setiap browser modern punya **DevTools**: kumpulan alat bawaan untuk melihat apa yang terjadi di balik halaman. Ini salah satu alat paling penting bagi QA.

## Cara membuka

- Tekan **F12**, atau
- **Ctrl + Shift + I** (Windows) atau **Cmd + Option + I** (Mac), atau
- Klik kanan halaman lalu pilih **Inspect**.

## Tab yang paling sering dipakai

| Tab | Fungsi | Contoh pemakaian QA |
|---|---|---|
| Elements | Melihat dan mengubah struktur HTML dan CSS | Mencari selector, memeriksa atribut elemen |
| Console | Melihat pesan dan error JavaScript | Menemukan error saat tombol tidak merespons |
| Network | Melihat semua request dan response | Memeriksa status code dan data API |
| Application | Melihat cookie dan local storage | Memeriksa data sesi login |
| Lighthouse | Mengukur performa dan aksesibilitas | Laporan cepat kualitas halaman |

## Mode perangkat

Ikon ponsel di pojok DevTools mengaktifkan **device mode**, untuk melihat tampilan halaman di berbagai ukuran layar tanpa perangkat fisik.

<Tips>Saat menemukan bug, buka tab Console. Error berwarna merah di sana sering menjadi petunjuk berharga untuk developer, jadi sertakan dalam bug report.</Tips>

## Ringkasan

DevTools dibuka dengan F12. Elements untuk struktur halaman, Console untuk error JavaScript, dan Network untuk request serta response.
