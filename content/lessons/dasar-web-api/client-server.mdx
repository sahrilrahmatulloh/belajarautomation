## Apa itu client dan server?

**Client** meminta data, dan **server** menjawabnya. Saat membuka sebuah halaman, browser menjadi client.

<Tips>Mulai pengujian dari alur yang paling sering dipakai pengguna.</Tips>

## Contoh request

```ts
const response = await fetch("https://contoh.com/api/profil");
console.log(response.status);
```

<Peringatan>Jangan menguji langsung di data production.</Peringatan>

## Ringkasan

| Pihak | Peran |
|---|---|
| Client | Mengirim request |
| Server | Mengirim response |
