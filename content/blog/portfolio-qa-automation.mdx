## Pendahuluan

Jelaskan mengapa portfolio membantu menunjukkan kemampuan, tanpa menjanjikan hasil lamaran.

## Isi Portfolio yang Baik

Bahas project yang bisa dijalankan, README yang jelas, dan struktur yang rapi.

## Ide Project

Beri beberapa ide project web dan API yang bisa diuji secara legal dan gratis.

## Merapikan GitHub

Bahas commit yang jelas, README, dan cara menjalankan test.

## Menjalankan Test di CI

Bahas manfaat menampilkan hasil test otomatis lewat CI.

## Kesalahan Umum

Bahas project hasil salinan tutorial, test yang gagal, dan tidak adanya dokumentasi.

## Kesimpulan

Rangkum langkahnya dan arahkan ke roadmap QA Automation Web.
